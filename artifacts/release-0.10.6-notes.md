Pacchetto completo Windows x64, generato dalla build GitHub Actions del commit c0dd928fd9b55c6a4816e3ac32edc39f8a89c2f0. Verifiche Windows e browser superate.

Scaricare PDF-MB-0.10.6-win-x64.zip, estrarre l’intera cartella e avviare PdfMB.Desktop.exe. Richiede .NET Desktop Runtime 10 e Microsoft Edge WebView2 Runtime. La guida aggiornata è inclusa e si apre con F1.

Include campi con regex, data/ora e NOW(), upload immagini, immagini statiche, pulsante email, password, lucchetto aperto per rimuoverla e miniature complete dei moduli.

[Build e verifiche](https://github.com/bottalico75marco-maker/pdfMB/actions/runs/39851119247). Il file .sha256 permette di verificare l’integrità dello ZIP.
