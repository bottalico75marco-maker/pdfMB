# PDF MB 0.12.1 · Aggiornamenti e release automatiche

- Controllo delle release stabili pubbliche di GitHub all’avvio, al massimo una volta al giorno; comando **Aiuto → Verifica aggiornamenti** per un controllo manuale.
- Avviso con versione disponibile, note di rilascio e download del pacchetto Windows x64. Il controllo è disattivabile dal menu Aiuto e la scelta resta memorizzata sul PC.
- Il controllo usa l’API pubblica di GitHub senza credenziali e non invia documenti. Connessione assente, timeout o limiti di GitHub non interrompono il lavoro sui PDF.
- A ogni tag `vX.Y.Z`, GitHub Actions verifica versione e note, esegue test desktop e browser, prepara ZIP e SHA-256 e pubblica la release solo dopo tutti i controlli e il caricamento del pacchetto.
- Include Testo unificato della 0.12.0: modifica del testo originale e inserimento dal pulsante con penna inclinata; raggruppamento prudente dei frammenti vicini, caselle compatte, salvataggio e Annulla/Ripeti comuni.

L’aggiornamento si installa estraendo lo ZIP completo; prima di sostituire la cartella in uso, chiudere PDF MB dopo aver salvato i documenti.
